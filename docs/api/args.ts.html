args_parse<TOutput extends Record<string, ArgValue> = Args>(unparsed_args: Args, schema: Schema<TOutput, any, string, unknown>): SchemaResult

Validates parsed CLI args against a fuz_schema schema.

Handles CLI-specific concerns before validation:

  1. Validates schema (cached) - returns its conflict issues if aliases conflict
  2. Expands aliases defined with meta(entry, {aliases: ['v']})
  3. Strips alias keys (required for object schemas, which refuse unknown keys)
  4. Validates with parse
  5. After validation, syncs no- prefixed boolean flags with their base keys

A boolean x and no-x given both ways, as by -C --color with C an alias of no-color, resolve to the side whose key comes later in unparsed_args (argv_parse orders keys by their last appearance in argv, so the side given last), and the other is set to its negation. An alias given with its canonical key gives way to it, and of two aliases of one key the earlier key wins; a key that gives way counts for neither value nor order, so --color -C -c with c an alias of color resolves to no-color. Only a no-x pair resolves by order.

Every arg key is an own key of what schema parses, __proto__, constructor, and toString included, so an object schema refuses them as unknown keys, and an entry named like an Object.prototype member reads as absent when it isn't given.

Schema analysis is cached per schema (WeakMap) for performance.

No array of the output is one of unparsed_args: those are copied. A with_default value is the same object on every parse: give an array or object entry its default with with_default_fn, as _: s.with_default_fn(s.array(s.string), () => []).

import {args_parse} from '@fuzdev/fuz_util/args.js';

args_serialize(args: Args, schema?: AnySchema): string[]

Serializes Args to CLI string array for subprocess forwarding.

Handles CLI conventions:

  • Positionals first, then flags
  • Single-char keys get single dash, multi-char get double dash
  • Boolean true becomes bare flag, false is skipped
  • undefined values are skipped
  • A no-x and x both truthy keep only the later key, the one args_parse and argv_parse let win
  • When schema provided, extracts aliases and prefers shortest form

Schema analysis is cached per schema (WeakMap) for performance.

import {args_serialize} from '@fuzdev/fuz_util/args.js';

args_validate_schema(schema: AnySchema): { ok: true; } | { ok: false; issues: SchemaIssue[]; }

Validates a fuz_schema schema for CLI arg usage.

Checks for:

  • Alias conflicts with canonical keys
  • Duplicate aliases across different keys

Each conflict is a SchemaIssue whose kind is 'alias_canonical_conflict' or 'duplicate_alias', whose path is the alias, and whose message says what it conflicts with.

Results are cached per schema (WeakMap). Safe to call multiple times.

argv_parse(argv: string[]): ParsedArgs

Parses raw CLI argv array into an Args object.

A lightweight, dependency-free alternative to mri/minimist with compatible behavior.

Features:

  • --flag → {flag: true}
  • --flag value → {flag: 'value'} or {flag: 123} (numeric coercion)
  • --flag=value → equals syntax
  • --flag= → {flag: ''} (empty string, differs from mri which returns true)
  • -f → {f: true} (short flag)
  • -f value → {f: 'value'}
  • -abc → {a: true, b: true, c: true} (combined short flags)
  • -abc value → {a: true, b: true, c: 'value'} (last flag gets value)
  • --no-flag → {flag: false} (negation prefix)
  • -- → stops flag parsing, rest become positionals
  • Positionals collected in _ array
  • Repeated flags become arrays
  • Keys are in the order of their last appearance, so args_parse can tell which of a no-x pair given both ways came last: --b --a --b → keys a, b (integer-like keys excepted, which JS always lists first)

Intentional differences from mri:

  • --flag= returns '' (mri returns true)
  • --flag= next returns {flag: '', _: ['next']} (mri takes next as the value)
  • ---flag returns {'-flag': true} (mri strips all dashes)
  • ['--flag', ''] preserves '' (mri coerces to 0)
  • --__proto__ works as a normal key (mri silently fails)

The returned object uses Object.create(null) to prevent prototype pollution and allow any key name including __proto__ and constructor.

import {argv_parse} from '@fuzdev/fuz_util/args.js';
