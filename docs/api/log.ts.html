Logger
#

log.ts view source

Simple, flexible logger with support for child loggers and automatic context.

Features:

  • Instance-based configuration (no global state)
  • Child loggers with automatic label concatenation
  • Parent chain inheritance for level, console, and colors
  • Colors by default only on a terminal, respecting FORCE_COLOR, NO_COLOR, NODE_DISABLE_COLORS, and CLAUDECODE (see colors)

colors
: boolean
gettersetter
#

Dynamic getter for colors - checks override, then parent, then the environment. Output is styled exactly when this is true, so an override forces colors on or off whatever the output stream is.

With no override in the parent chain, the default is decided in order:

  • FORCE_COLOR set: on for '', '1', '2', '3', or 'true', as in Node, otherwise off
  • NO_COLOR, NODE_DISABLE_COLORS, or CLAUDECODE set and non-empty, or TERM of 'dumb': off. The CLAUDECODE check disables colors in Claude Code environments where ANSI color codes may not render correctly in the output.
  • otherwise on only when the logger writes to the global console and both stdout and stderr are terminals, so a custom console defaults to off

Without process the default is on.

LogLevel
#

log.ts view source

type "off" | "error" | "warn" | "info" | "debug"

Log level hierarchy from least to most verbose.

  • 'off': No logging
  • 'error': Only errors
  • 'warn': Errors and warnings
  • 'info': Errors, warnings, and info (default)
  • 'debug': All messages including debug
